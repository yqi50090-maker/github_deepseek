# projects-memory

一套给 AI agent 用的「项目记忆」技能：定义收工时的路由规则，把进度写进对应项目的交接文件，把新结论追加进长期记忆。

## 设计

- 主体记忆（跨会话共用）：`main.md`，每个会话开场读
- 项目分支：每个活一个 `项目信息.md`，内含
  - `§〇 当前交接`（覆盖写）：身份 / 上次进度 / 下一步 / 卡点 / 细节在哪
  - `§五 长期记忆`（只追加）：一条一行，带日期，只记结论
- 写前先看文件 mtime，避免多会话并发覆盖
- 判据：只记结论不记过程；每次写回不超过 10 行

## 结构

```
projects_memory/
├── SKILL.md            # 收工路由与写入规则
└── <活>/
    └── 项目信息.md      # 每个活一个文件
```

## 安装

1. 把本目录复制到 `~/.dsh/skills/projects_memory/`
2. 在会话里说「收工」触发；或让 agent 读 `SKILL.md`

## 注意

本仓库只包含**框架**（SKILL.md），不包含任何实际项目记忆。项目内容属于个人数据，应留在本地。
