## 收工时怎么路由

1. **判断本轮内容主题**：
   - 天线 / 射频 / 仿真 / 论文 / 实验报告 → `antenna\`
   - DSH / 启动器 / 插件 / 人格 / 记忆系统 / 环境清理 → `deepseek_optimize\`
   - 养鱼 / B 站私信 / 评论分享 / 日记偏好校准 → `bili_whale\`
   - 其他 → 按下一条新建
2. **新建活**：在根目录建 `<英文名>\项目信息.md`（模板同下），并登记到「活清单」。
3. **写入**：
   - `§〇 当前交接`（**覆盖**）：身份 / 上次进度 / 已定结论 / 下一步 / 卡点 / 细节在哪，≤ 4 KB
   - `§五 长期记忆`（**追加**）：一条一行，带日期，只记结论
   - **并发写保护（2026-11-01 加）**：写 §〇 前先 stat 该文件，若 mtime 晚于自己本轮读到的版本 → **先重读整段再写**，不要拿旧内容覆盖。同一时间可能有养鱼会话 / 主会话 / QQ 桥三路在写同一份 §〇，覆盖式写入最易丢结论。
4. **判据**：只记结论不记过程；每次 ≤ 10 行；不猜设计参数。

## 读
